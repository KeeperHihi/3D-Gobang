# Nebula Cube 3D 五子棋

在线匹配的 3D 联机五子棋。棋盘是立方体，任意空间方向连成 5 子即获胜。

## 当前默认规则

- 棋盘尺寸：`8 x 8 x 8`
- 连线胜利条件：`5 子`
- 每回合默认落子时限：`300s`

## 主要交互（已落地）

- 旋转/缩放镜头后，视角保持当前位置，不会被系统自动复位。
- “战术辅助提示”默认关闭；仅在玩家主动开启后显示候选提示位。
- 对手刚落子的格子会闪烁数次，提醒当前玩家。
- 已聚焦某层时，只允许点击该层可落子位；点击其他层不会切层。
- 鼠标移入候选落子位立即高亮。
- 外层立方体线框已移除。
- 支持通过滑杆连续调节“未聚焦层”显示清晰度（透明度）。
- “展开更多状态”面板支持纵向滚动，且按钮已简化为设置行操作。
- 默认 HUD 为极简模式（回合信息 + 主动作 + 层导航），更多状态可按需展开。
- 当轮到你且“战术辅助提示”关闭时，主动作按钮会提供“一键开启提示并推荐”，避免操作死路。
- 若开启“超时护航”，即使提示开关关闭，在临近超时窗口也会自动执行一次兜底合法落子（优先制胜/防守）。
- 匹配页会在在线空闲与“开始匹配”意图阶段提前预热 3D 战场，降低进房等待感。
- 预热失败时可在匹配页使用“**一键重试预热**”恢复，不影响继续匹配主流程。
- 预热策略具备网络感知：弱网或省流量模式下默认按“用户意图触发”预热，避免空闲时盲目下载大资源。
- 排队中若预热失败会自动按退避节奏重试（最多 3 次），并保留手动重试入口。
- 对局冷启动采用分阶段渲染：先保证棋盘可交互与稳帧，再渐进恢复星空/粒子等氛围特效。
- 棋盘主层已切换为分桶实例化渲染（instanced mesh），降低稳态 draw call 与交互抖动。
- 悬停高亮已与主实例布局解耦：采用独立 overlay 实时反馈，避免高频 hover 触发整盘重算。
- HUD 时钟已升级为自适应刷新频率（关键窗口提频、平稳阶段降频），减少长局空转重渲染。
- `BoardScene` 已进行 memo 渲染隔离，HUD 时钟刷新不再默认拉动 3D 场景重渲染。
- 对局场景已采用“核心可玩优先 + 特效后流式加载”：棋盘交互先就绪，星空/粒子/胜线特效按阶段补齐。
- 自动质量模式下，低 FPS 会触发“冷静模式”降低渲染预算以优先保证流畅度。

## 本地启动

### 环境要求

- Node.js 18+
- npm 9+

### 安装依赖

```bash
npm install
npm --prefix server install
```

### 开发模式

```bash
npm run dev
```

- 前端（Vite）：`http://localhost:5173`
- 后端（Socket.IO + Express）：`http://localhost:3001`

## 测试与构建

```bash
npm test
npm run build
```

## 可选环境变量

前端：

- `VITE_SERVER_URL`：后端地址，默认 `http://localhost:3001`

后端：

- `PORT`：服务端口，默认 `3001`
- `FRONTEND_ORIGIN`：允许跨域来源，默认 `http://localhost:5173`

## 目录结构

- `src/`：前端页面、UI、交互逻辑、3D 场景
- `server/src/`：匹配、房间状态、Socket 事件
- `shared/`：前后端共享协议与棋盘/胜负判定逻辑
